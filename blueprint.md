# Project Blueprint

## Overview

This project is a website for a travel agency specializing in tours, experiences, and vehicle rentals in Cyprus. The entire site is in Polish.

## Style, Design, and Features

### General
*   **Language:** Polish
*   **Framework:** Astro.js
*   **Styling:** Bold, modern design with a professional color scheme, gradients, and drop shadows.
*   **Images:** Local images are stored in the `public/images` directory for better performance and reliability.

### Pages
*   **Home (`/`):** Hero section with a call-to-action, featured tours, car rentals, and bike rentals.
*   **Tours (`/wycieczki`):** A page listing all available tours and experiences using a card-based layout.
*   **Rentals (`/wynajem`):** A page for car and bike rentals using a card-based layout.
*   **About Us (`/o-nas`):** A page with information about the company.
*   **Contact (`/kontakt`):** A contact form and contact information.

### Components
*   **Layout:** A global layout with a redesigned header and a new footer.
*   **Card:** A reusable card component for displaying tours and rentals with images and descriptions.
